# @pistachio/extension-api

The Pistachio extension API. The spec — normative — is [`docs/extensions.md`](../../docs/extensions.md) (§3 the manifest, §4 the wire, §5 the API, §6 security).

| Export | What |
| --- | --- |
| `.` | `./capabilities`, `./manifest`, `./wire` and the wire's data shapes (`src/api-types.ts`) |
| `./manifest` | `manifestSchema` (zod), `parseManifest`, `validateManifest`, `manifestFiles`, `manifestAsks`, `widenedAsks` |
| `./capabilities` | `CAPABILITIES`, their tiers and the approval sheet's fixed sentences |
| `./sheet` | `sheetFor`, `hostsInWords`, `manifestHash` (node only: `node:crypto`) |
| `./wire` | the two channels, `EXT_METHOD_NAMES`, events, invocation kinds, `ExtReply`, `ExtError`, rate limits, handler timeouts |
| `./runtime` | `buildPistachio` — the `pistachio` global, built in an extension page's own world by `apps/desktop/src/preload/extension.ts` over the preload's `__pistachioWire` |
| `./types` | `pistachio.d.ts`, the global `pistachio` authors program against |
| `./schema` | `schema/pistachio-extension.schema.json`, generated by `pnpm --filter @pistachio/extension-api schema` |

`src/api-types.ts` is the per-method wire contract (`ExtMethodMap`, `ExtEventMap`, `ExtInvokeMap`) main's dispatch table is checked against; `test/wire.test.ts` keeps it in step with `pistachio.d.ts`, and `test/runtime.test.ts` holds the runtime to `pistachio.d.ts`.

For authors, and for coding agents in `~/Pistachio/Extensions/`: [`AGENTS.md`](AGENTS.md) (the guide), [`skill/SKILL.md`](skill/SKILL.md) (the same as a Claude Code skill), and three loadable templates in [`templates/`](templates) — `panel`, `bar-command`, `agent-tool`.

Tests: `pnpm --filter @pistachio/extension-api test`; types: `pnpm --filter @pistachio/extension-api check-types`.
