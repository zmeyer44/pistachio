# Word count (template: an agent tool)

Declares a `read` tool, `word_count`, that the agent can call; the worker answers it with JSON.
Asks only for `agent:tools`; the person can still switch off *Agent can use it*.
Copy the folder into `~/Pistachio/Extensions/`, change `id` and `name`, approve it in Pistachio.
After each save, read `.pistachio/status.json` in the folder.
