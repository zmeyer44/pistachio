# Tab list (template: panel)

A Ledge icon whose panel lists the current space's tabs, each with a Show button.
Asks for `tabs:read` and `tabs:write`; no worker — the panel's own script does the work.
Copy the folder into `~/Pistachio/Extensions/`, change `id` and `name`, approve it in Pistachio.
After each save, read `.pistachio/status.json` in the folder.
