# Hello (template: a Bar command)

`/hello <name>` in the Bar wakes the worker, which shows a toast and, given a name, opens `hello.html` as a desk window.
No permissions: declared commands, toasts and the extension's own pages are free.
Copy the folder into `~/Pistachio/Extensions/`, change `id` and `name`, approve it in Pistachio.
After each save, read `.pistachio/status.json` in the folder.
